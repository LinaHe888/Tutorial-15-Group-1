# Activity Log Folder

## Purpose
This folder stores the team contribution records required for the final Assignment 1 submission.

## Current Contents
- `activity-log.md`: editable contribution log in N×N matrix format
- `activity-log.pdf`: exported PDF version for submission
- `activity-log.html`: intermediate export file generated during PDF conversion
- `README.md`: folder description

## Role in the Assignment
This folder is used to document:
- each member’s contribution
- the N×N contribution matrix
- evidence of team participation across Tasks 1–5

## Notes
The PDF version is the main submission artefact, while the Markdown file is the editable source.
