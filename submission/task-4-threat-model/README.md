This folder contains the materials for Task 4, which explains why the identified vulnerability matters from the attacker’s perspective.

Task 4 is used to explain:

- why the generation method is unsuitable for its security role

- how a realistic attack path would work step by step
- what impact the weakness has on authentication integrity
