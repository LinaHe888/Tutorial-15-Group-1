# Shared Assets

## Purpose
This folder stores shared materials that can be reused across multiple tasks in Assignment 1.

## Current Contents
- `README.md`: folder description and usage notes

## Intended Use
This folder can be used for items that support more than one task, such as:
- shared templates
- reusable screenshots or diagrams
- common reference notes
- terminology or naming conventions
- materials prepared during final submission integration

## Notes
At the moment, this folder is mostly reserved for cross-task materials rather than task-specific evidence.
