# Task 1 - Decompilation

## Purpose
This folder contains the materials for Task 1, which focuses on unpacking and decompiling the APK so that the application structure and source-level logic can be inspected.

## Current Contents
- `apk_analysis_20260312_2119.zip`: packaged Task 1 analysis output, including decompilation results and supporting materials
- `README.md`: folder description

## Role in the Assignment
Task 1 is used to show that the APK was successfully unpacked and that key artefacts could be located, including:
- the package name
- the Android manifest
- the launcher / main activity
- key authentication-related classes such as registration and login logic

## Expected Evidence
