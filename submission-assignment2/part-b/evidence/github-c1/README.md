# GitHub C1 Evidence Folder

Store only redacted proof artifacts from team-owned GitHub test assets.

Suggested contents:
- `scope-screenshots/`: GitHub Bug Bounty scope/rules screenshots or PDFs.
- `setup-screenshots/`: owned org/repo/account role setup screenshots.
- `api-responses-redacted/`: REST/GraphQL responses with tokens/cookies removed.
- `test-notes/`: one note per attempted test case.

Never commit tokens, cookies, session IDs, real PII, or third-party data.
