What Is This App?

Package: com.example.mastg_test0019

  • Single-activity WebView browser
  • Loads http://www.example.com on launch
  • No login, no local storage, no authentication
  • Every network decision is deliberately insecure

(OWASP MASVS/MSTG test case — vulnerable by design)

Network Behavior

What travels over the network?

StepActionProtocolSecurity
1DNS lookupUDP/53Unencrypted
2HTTP GET requestHTTP/80Cleartext
3Server responseHTTP/80Cleartext
4WebView renders—No integrity check

No TLS. Any node on the path can read or modify traffic.

System Model

User → MainActivity → WebView → HTTP GET → Wi-Fi/Cell → Internet → Server
              │           │
              └─ WebViewClient ─┘
                 (ignores SSL errors)
  • WebViewClient: onReceivedSslError → proceed()
  • HostnameVerifier: returns true for any hostname
  • Manifest: usesCleartextTraffic="true"

The Attacker

On-Path MITM

Position: Same Wi-Fi, rogue access point, compromised router

Capabilities:

  1. Read all HTTP traffic (no encryption)
  2. Modify HTML/JS before it reaches the WebView
  3. Impersonate the server (certificate validation disabled)

Skill required: Low — mitmproxy, Burp Suite, or Wireshark

Scenario A

Cleartext Eavesdropping

Phone ──HTTP GET──> [Attacker on Wi-Fi] ──HTTP GET──> Server
                          │
                          ▼
                    "GET / HTTP/1.1
                     Host: www.example.com"

Attacker sees headers, cookies, query parameters, and full response body — zero effort.
